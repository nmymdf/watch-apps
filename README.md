# compass-watch

Galaxy Watch7 44mm (Wear OS) compass + altitude app. 作者：ArchieKUO

- Screen A: rotating compass dial, heading, altitude (barometer, calibrated by GPS), pressure
- Screen C: compass calibration (tap the centre of screen A)
- Push to `main` -> GitHub Actions builds the APK -> it appears on the `apk` branch as `compass-watch-v<version>.apk`
